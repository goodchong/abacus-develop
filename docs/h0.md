# H0 workflow and file contract

## Scope

`calculation` must be `get_h0` and `basis_type` must be `lcao`. Any legacy
calculation type, `gamma_only`, K-point, H(k), overlap-matrix, solver, SCF, or
old matrix-output keyword is rejected as an unknown or invalid INPUT keyword.
A `KPT` file is neither opened nor required.

`h0_type` is mandatory:

- `core` builds `T + V_nl + V_loc`. It does not allocate charge density,
  density matrices, wavefunctions, or a solver.
- `full` first initializes `rho0`, then sets nonlinear core charge, normalizes
  the valence density, constructs the initial local/Hartree/XC potential, and
  immediately projects it into H(R). There is no charge symmetrization or
  density update after this point.

Only the built-in LDA and GGA functionals listed by `abacus -h
dft_functional` are accepted. Libxc, meta-GGA, hybrid, HF, and EXX paths are
not built.

## Spin behavior

`nspin` accepts `1`, `2`, or `4`. For collinear `nspin=2`, the spin-independent
`core` matrix is written only once; `full` writes separate spin-up and
spin-down matrices. `nspin=4` retains the complex two-component spinor basis,
including noncollinear and spin-orbit nonlocal terms.

## CSR output

Matrix values are in Ry. The writer retains ABACUS text CSR numeric layout:
the existing basis-size and R-block-count fields are not shifted. Formula,
`h0_type`, physical `nspin`, and units appear only in an existing comment line.

An entry is stored exactly when `abs(value) > h0_sparse_threshold`.
`h0_precision` is the number of significant digits and accepts `1` through
`17`. MPI contributions are summed before rank zero writes the files. R-block
enumeration, empty blocks, sorted unique column indices, and `nbasis + 1` CSR
row pointers are preserved.

The real-space Hermitian relation is

```text
H_ij(R) = conj(H_ji(-R)).
```

## Initial density files

For `h0_type=full`, `init_chg=file` requires the normal ABACUS restart density
or `chg.cube`/spin-resolved cube files in `read_file_dir`. `init_chg=auto` uses
the same priority but falls back to atomic density if every file read fails.
`init_chg` is ignored by `core`.

## Regression baselines

`tests/h0/reference` contains gzip-compressed CSR files frozen from the
pre-crop first-Hamiltonian initialization. The end-to-end tests compare R
support, CSR structure, and every value using absolute/relative tolerance
`1e-10`. They cover `core/full x nspin=1/2/4`, initial-density file/fallback
behavior, strict threshold boundaries, output precision, Hermiticity,
OpenMP, and MPI 1/2/4-rank consistency.
